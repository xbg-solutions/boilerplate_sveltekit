# Firebase Development Skill

This skill provides comprehensive Firebase guidance from two official/community sources.

## Skill Structure

### From firebase/agent-skills (Official)
- `firebase-basics/` — Project setup, CLI, web configuration
- `firebase-auth-basics/` — Authentication providers, client SDK, security rules
- `firebase-firestore-standard/` — Firestore Standard: data model, queries, indexes, security rules
- `firebase-firestore-enterprise-native-mode/` — Firestore Enterprise: advanced features, Python SDK
- `firebase-hosting-basics/` — Static hosting configuration and deployment
- `firebase-app-hosting-basics/` — Full-stack SSR hosting (Next.js, Angular)
- `firebase-local-env-setup/` — Emulators, local development, agent-specific setup
- `firebase-ai-logic-basics/` — Firebase AI Logic (Gemini API) integration

### From SpillwaveSolutions/using-firebase (Community)
- `cloud-functions/` — Cloud Functions (both generations), deployment, secrets, GCP integration

### Additional
- `FIREBASE.md` — Firebase overview and service reference

## Usage
Each subdirectory contains a `SKILL.md` with guidance and a `references/` directory with detailed documentation. Read the relevant `SKILL.md` first, then consult references as needed.
